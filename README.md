# CF · 运输船（网页版 FPS）

穿越火线经典地图「运输船」的网页复刻演示，纯前端单文件实现（Three.js 本地化，无其他依赖）。

## 🎮 玩法

- **WASD** 移动 · **鼠标** 瞄准 · **左键** 射击 · **Shift** 疾跑 · **Space** 跳跃 · **C** 下蹲
- **R** 换弹 · **1** M4A1 · **2** 沙漠之鹰 · **3** 军刀 · **4** AWM 大狙
- AWM 大狙：**右键** 开镜，**V / 滚轮** 在高倍镜与二倍镜之间切换
- 团队竞技：蓝方 VS 红方，先到 **30 杀** 获胜；爆头伤害更高，连杀有播报

## ✨ 特性

- 还原运输船布局：双层集装箱三通道、出生点掩体、舷墙栏杆、驾驶舱、起重机、海面与云层
- AI 佣兵：巡逻寻路、沿墙滑动、卡住自愈、红方追杀玩家、互相交火、倒地动画
- 打击感：后坐力、抛弹壳、枪口火光、弹道、命中/击杀反馈、受击方向指示、立体声方位
- 内嵌浏览器/触屏适配：指针锁定失败自动切换拖拽转向，支持虚拟摇杆

## 🚀 运行

直接打开 `index.html`，或访问线上部署地址。建议 Chrome / Edge，按 **Ctrl+F5** 强刷缓存。
